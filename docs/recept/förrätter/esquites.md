# Esquites
Mexikansk majsröra som är beorendeframkallande god. Äts som ett snacks eller en förrätt tillsammans med varma nachochips.

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">1</span> st silverlök, finhackad
- [ ] <span class="qty">3</span> klyftor vitlök, finhackade
- [ ] <span class="qty">2</span> st jalapeños, finhackade
- [ ] <span class="qty">50</span> g smör
- [ ] <span class="qty">420</span> g majskorn (ca 3 små burkar)
- [ ] <span class="qty">4</span> msk majonnäs
- [ ] <span class="qty">75</span> g vitost, fint smulad
- [ ] <span class="qty">1</span> dl parmesanost, finriven
- [ ] <span class="qty">2</span> st limefrukter, skurna i klyftor
- [ ] <span class="qty">1</span> kruka färsk koriander, grovhackad
- [ ] chilipeppar, efter smak
- [ ] salt
- [ ] svartpeppar
- [ ] <span class="qty">200</span> g nachochips

## Instruktioner
- [ ] Sätt ugnen på 200 grader. Lägg nachochipsen på en plåt och värm dem i ugnen i 5–10 minuter.
- [ ] Smält smöret i en stekpanna och stek lök, vitlök och jalapeño på medelvärme tills de mjuknat. Häll av majsen. Tillsätt majsen och låt fräsa i några minuter tills den blir varm och får lite färg. Smaka av med salt och svartpeppar.
- [ ] Rör ner majonnäsen i den varma majsblandningen.
- [ ] Fördela majsröran i fyra glas eller små skålar. Toppa med smulad vitost, riven parmesan, chilipeppar och koriander. Servera med limeklyftor att pressa över efter smak.
- [ ] Servera direkt tillsammans med de varma nachochipsen och låt alla skopa upp den krämiga majsröran.
