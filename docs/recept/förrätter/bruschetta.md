# Bruschetta
En klassisk italiensk förrätt.

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">1</span>st Baguette
- [ ] <span class="qty">500</span>g Tomater
- [ ] <span class="qty">2</span>st Vitlök
- [ ] <span class="qty">1</span>dl Basilika
- [ ] <span class="qty">2</span>matskn Olivolja

## Instruktioner
- [ ] Tärna tomaterna.
- [ ] Blanda med hackad basilika, olivolja och salt/peppar.
- [ ] Rosta brödskivorna.
- [ ] Gnid vitlök på brödet och lägg på tomatblandningen.
