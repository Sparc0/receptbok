# Krämig myspasta
En pasta med smör, färskost, soja, chiliflakes, grädde, parmesan som toppas med syrlig ruccola. Perfekt att laga när man inte orkar lägga mycket tid i köket men som ändå känns lyxigt och gott!

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">50</span>g Smör
- [ ] <span class="qty">3</span>st Vitlöksklyftor
- [ ] <span class="qty">2</span>tsk Chiliflakes (milda)
- [ ] <span class="qty">1.5</span>tsk Japansk soya
- [ ] <span class="qty">1</span>dl Vispgrädde
- [ ] <span class="qty">4</span>dl Finriven parmesan
- [ ] <span class="qty">200</span>g Färskost
- [ ] Peppar
- [ ] <span class="qty">300</span>g Tagliatelle
- [ ] <span class="qty">100</span>g Ruccola
- [ ] Rödvinsvinäger
- [ ] Olivolja
- [ ] Salt

## Instruktioner
- [ ] Börja koka pastan.
- [ ] Finriv parmesanen och finhacka vitlöken.
- [ ] Bryn smöret tillsammans med vitlöken i en djup panna.
- [ ] Tillsätt soja och chiliflakes och låt brynas ihop.
- [ ] Tillsätt sedan färskost och grädde. Låt komma ihop.
- [ ] Peppra.
- [ ] Tillsätt parmesan och smaka av med mer chiliflakes, soja och peppar.
- [ ] När det smakar bra, tillsätt pastan direkt från pastavattnet (som du slevar upp med pastaslev och låter vattnet rinna av).
- [ ] Blanda ruccola med rödvinsvinäger, salt och olja tills du är nöjd med smaken.
- [ ] Servera pastan med ruccolasalladen.
