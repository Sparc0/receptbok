# Pasta med Burrata
Pasta i en otroligt krämig och smakrik tomatsås som toppas med en burrata.

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">4</span> portioner linguine
- [ ] <span class="qty">2</span> st schalottenlökar
- [ ] <span class="qty">2-3</span> st vitlöksklyftor
- [ ] <span class="qty">2</span> dl vitt vin
- [ ] <span class="qty">1</span> paket krossade tomater
- [ ] <span class="qty">3</span> msk tomatpuré
- [ ] <span class="qty">70</span> g babyspenat
- [ ] <span class="qty">1</span> st grönsaksbuljong
- [ ] <span class="qty">2</span> tsk torkad oregano
- [ ] <span class="qty">1</span> tsk torkad basilika
- [ ] Salt och peppar
- [ ] <span class="qty">3.5</span> dl grädde
- [ ] <span class="qty">10</span> st körsbärstomater
- [ ] Burrata
- [ ] Massa parmesan

## Instruktioner
- [ ] Hacka schalottenlök och vitlök och fräs på i olivolja.
- [ ] Tillsätt körsbärstomater och vitt vin och låt det puttra på ett tag. Addera sedan tomatpurén.
- [ ] Häll i krossade tomater, grädde, grönsaksbuljong och alla kryddor. Låt det puttra några minuter.
- [ ] Koka pastan al dente.
- [ ] Tillsätt 1 dl av pastavattnet i såsen.
- [ ] Lägg i pastan och massa parmesan i tomatsåsen och låt det kräma till sig.
- [ ] Servera med en burrata på toppen.
