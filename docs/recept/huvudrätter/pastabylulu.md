# Pastabylulu
Bucatini con funghi e crema di tartufo

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">4</span> port valfri pasta
- [ ] <span class="qty">300</span>g skogschampinjoner
- [ ] <span class="qty">2</span> st schalottenlökar
- [ ] <span class="qty">2</span> dl vitt vin
- [ ] <span class="qty">2</span> klyftor vitlök
- [ ] <span class="qty">3</span> dl vispgrädde
- [ ] <span class="qty">3</span> tsk mushroom soy
- [ ] <span class="qty">1</span> msk kantarellfond
- [ ] Vit tryffelolja
- [ ] Svartpeppar
- [ ] Parmesanost
- [ ] Burrata
- [ ] Persilja

## Instruktioner
- [ ] Hacka lök, vitlök och skogschampinjoner och fräs i olivolja. Häll på vitt vin och låt det puttra på någon minut.
- [ ] Tillsätt grädden och rör om.
- [ ] Smaka av med soya, kantarellfond, tryffelolja och svartpeppar.
- [ ] Koka pastan al dente.
- [ ] Häll i pasta, hackad persilja och parmesan i såsen. Rör om ordentligt.
- [ ] Servera med burrata på toppen
