# Pasta Carbonara
En krämig italiensk klassiker.

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">400</span>g Pasta
- [ ] <span class="qty">150</span>g Guanciale eller pancetta
- [ ] <span class="qty">50</span>g Pecorino Romano
- [ ] <span class="qty">3</span>st Ägg
- [ ] <span class="qty">1</span>tsk Svartpeppar

## Instruktioner
- [ ] Koka pastan.
- [ ] Stek guanciale tills det är krispigt.
- [ ] Vispa ihop ägg och ost.
- [ ] Blanda pastan med guanciale och ta av från värmen.
- [ ] Rör snabbt ner äggblandningen för att skapa en krämig sås.
