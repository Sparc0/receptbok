# Chokladmousse
En luftig och lyxig dessert.

**Antal personer:** <span class="servings-count">4</span>

## Ingredienser
- [ ] <span class="qty">200</span>g Mörk choklad
- [ ] <span class="qty">2</span>dl Grädde
- [ ] <span class="qty">3</span>st Ägg
- [ ] <span class="qty">0.5</span>dl Socker

## Instruktioner
- [ ] Smält chokladen.
- [ ] Vispa äggvitor med socker.
- [ ] Blanda chokladen med äggulor.
- [ ] Vänd försiktigt ner grädde och äggvitor.
- [ ] Låt stelna i kylskåp.
